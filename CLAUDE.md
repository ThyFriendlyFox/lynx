# CLAUDE.md

This repository is governed by `agent-kit/`. There is exactly one contract.

Start at [agent-kit/ROUTING.md](agent-kit/ROUTING.md). It names the file that
governs the situation you are in.

The 4 rules that apply before you read anything else:

1. `agent-kit/AGENTS.md` is binding whenever you touch code. It holds the
   invariants and the landmine map.
2. `agent-kit/ROADMAP.md` decides what gets built. Work that is not on it gets
   added to it first.
3. `./verify/verify.sh` must pass before any push.
4. `agent-kit/TONE.md` governs your own words; `agent-kit/docs/STYLE.md`
   governs every word a user reads.
